# Code of Conduct

## Our standard

Contributors and maintainers are expected to communicate respectfully, welcome
constructive feedback, and focus discussion on the project and its technical
tradeoffs. Harassment, discrimination, personal attacks, and the publication of
another person's private information are not acceptable.

## Scope

This standard applies to repository issues, pull requests, reviews, discussions,
and other spaces where someone is representing this project.

## Reporting

Report unacceptable behavior to the repository owner through an appropriate
private GitHub contact channel. Do not publish sensitive personal information in
a public issue. Reports will be reviewed promptly and handled as confidentially
as the available channel permits.

## Enforcement

Maintainers may edit or remove inappropriate contributions, issue a warning,
temporarily restrict participation, or permanently remove someone from project
spaces. Decisions should be proportionate, documented privately when possible,
and made without retaliation against good-faith reporters.
